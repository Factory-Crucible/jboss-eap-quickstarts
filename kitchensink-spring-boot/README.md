# Kitchensink Spring Boot 3

Spring Boot 3 migration of the classic **“kitchensink”** quick-start originally written for JBoss EAP.  
The service exposes a small CRUD API for **Member** entities and demonstrates:

* Spring Boot 3 + Java 21 auto-configuration  
* Spring Data JPA (Hibernate 6) + MySQL 8  
* Bean Validation & global exception handling  
* Lombok boiler-plate reduction  
* SpringDoc OpenAPI 3 with Swagger UI  
* Unit, web-layer and Testcontainers integration tests

---

## 1  Prerequisites

| Tool | Recommended Version |
|------|---------------------|
| **JDK** | 21 |
| **Maven** | 3.9 ( `./mvnw` wrapper bundled ) |
| **Docker Desktop** | 4.x (for local MySQL) |
| curl / Postman | – |

> **Tip:** Windows users can substitute `./mvnw` with `mvnw.cmd`.

---

## 2  Clone the Project

```bash
git clone https://github.com/Factory-Crucible/jboss-eap-quickstarts.git
cd jboss-eap-quickstarts/kitchensink-spring-boot
```

---

## 3  Start MySQL (Docker Compose)

A ready-to-run compose file is included.

```bash
docker compose up -d         # starts MySQL 8 on port 3306
```

Default credentials:

```
user    : root
password: change-me
database: kitchensink
```

Override with environment variables or adjust `application.properties`.

## 4  Build & Test

```bash
# clean build + all tests
./mvnw clean verify
```

Tests include:

* **Unit** – Mockito
* **Web layer** – MockMvc
* **Integration** – Testcontainers-MySQL

## 5  Run the Application

### 5.1  Via Maven

```bash
./mvnw spring-boot:run
```

### 5.2  As Runnable JAR

```bash
./mvnw -q package
java -jar target/kitchensink-spring-boot-0.0.1-SNAPSHOT.jar
```

Server starts on **http://localhost:8080**.

### 5.3  With Docker (optional)

```bash
./mvnw spring-boot:build-image      # buildpacks image
docker run --network host \
  -e SPRING_DATASOURCE_PASSWORD=change-me \
  kitchensink-spring-boot:0.0.1-SNAPSHOT
```

---

## 6  Configuration

Edit `src/main/resources/application.properties`.

Key properties:

| Property | Purpose | Default |
|----------|---------|---------|
| `spring.datasource.url` | JDBC URL | `jdbc:mysql://localhost:3306/kitchensink` |
| `spring.datasource.username` | DB user | `root` |
| `spring.datasource.password` | DB password | `change-me` |
| `spring.jpa.hibernate.ddl-auto` | Schema mode | `update` |
| `server.port` | HTTP port | `8080` |

Use environment variables (e.g. `SPRING_DATASOURCE_PASSWORD`) for overrides.

## 7  API Usage

### 7.1  Swagger UI

Browse to:

```
http://localhost:8080/swagger-ui.html
```

Interactive documentation generated by SpringDoc.

### 7.2  Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/members` | List all members |
| GET | `/api/members/{id}` | Retrieve member by id |
| POST | `/api/members` | Register new member |

#### Example – Create Member

```bash
curl -X POST http://localhost:8080/api/members \
  -H "Content-Type: application/json" \
  -d '{
        "name": "Alice Example",
        "email": "alice@example.com",
        "phoneNumber": "1234567890"
      }' -v
```

* **201 Created** → `Location` header points at the new resource  
* **400 Bad Request** → validation errors in JSON map  
* **409 Conflict** → duplicate email

## 8  Troubleshooting

| Problem | Solution |
|---------|----------|
| _Cannot connect to MySQL_ | Ensure `docker compose ps` shows `healthy`, port 3306 not blocked. |
| _Duplicate email conflict_ | Use unique email or DELETE existing member first. |
| Tests fail on Apple M-series | Add `testcontainers.properties` with `ryuk.container.image=ghcr.io/testcontainers/ryuk:0.5.2`. |
